# Break the App – Hint Page

This repository contains a small static page used as part of the **Break the App** testing challenge.

The page is connected to one of the hidden clues available inside the application and is intended to support the game experience.

It does not contain the solution to the challenge directly.

## Purpose

- part of the QA Conference Portal game
- provides an external hint for participants
- used as a target page for an in-app QR code
- deployed with GitHub Pages
